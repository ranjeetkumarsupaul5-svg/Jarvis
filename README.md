# Jarvis AI Assistant

A Python-based AI Voice Assistant.

## Features

- Face Authentication
- Voice Assistant
- Speech Recognition
- Text to Speech
- Groq AI Chat
- Open Applications
- Web Search

## Technologies Used

- Python
- OpenCV
- Flask
- HTML/CSS/JavaScript
- Groq API

## Installation

```bash
git clone https://github.com/YOUR_USERNAME/Jarvis.git
cd Jarvis
pip install -r requirements.txt
python main.py
```
