# 🤖 Jarvis AI Assistant

An AI-powered Voice Assistant built using Python, OpenCV, Flask, Speech Recognition, and Groq AI.

---

## 🚀 Features

- 🔐 Face Authentication
- 🎙️ Voice Command Recognition
- 🤖 AI Chat using Groq API
- 🔊 Text-to-Speech
- 🌐 Open Websites
- 💻 Open Desktop Applications
- 🔍 Web Search
- 🖥️ Flask Web Interface

---

## 🛠️ Technologies Used

- Python
- OpenCV
- Flask
- HTML
- CSS
- JavaScript
- SpeechRecognition
- PyAutoGUI
- pyttsx3
- Groq API

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/ranjeetkumarsupaul5-svg/Jarvis.git
```

Go to the project folder

```bash
cd Jarvis
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the project

```bash
python main.py
```

---

## 🔑 Environment Variables

Create a `.env` file in the project root.

```
GROQ_API_KEY=YOUR_GROQ_API_KEY
```
